# インサイト統合（2026-09-14）

3本のリサーチ（[01-user-insight](01-user-insight.md) / [02-ux-design](02-ux-design.md) / [03-competitive](03-competitive.md)）の統合。プロダクト判断の基準として harness に畳み込む。

## コアの結論（3本が一致）

tt-tactics 固有の価値 = **分岐ツリー(仮説) × ログ × 勝率 の閉ループを、AI が言語化して回すこと**。これは競合の誰も達成していない空白。価値が「薄い」と感じるのは、ループが前面に出ておらず、データが「次の一手」に翻訳されていないから。

## 確定した設計原則

1. **開けば次の一手が決まっている** — ホームは機能一覧でなく「今日の1カード＋1アクション」。判断コストをアプリが肩代わりする。
2. **記録は確認するだけ** — 前回値プリフィル＋3択。試合直後を最重要の記録機会にする。勝敗だけでなく「崩れ方」を1行残す価値が高い。
3. **可視化は次の行動に翻訳** — ヒートマップ・勝率・トレンドを「だから次はこれ」まで落とす。数字の羅列で止めない。
4. **AI はカードで先回り** — チャットで待たせず、記録後やホームにインサイトカードを差し込む。末尾は必ずツリー/課題への1タップ。根拠必須（verify/citations 済み）、断定しない。
5. **強い動機づけとやさしい逃げ道** — ゆるい週目標＋休む選択肢。個人利用ゆえ煽らない。継続は「連続日数」でなく「検証した課題数」で数える。

## 情報設計

4タブ（戦術/課題/練習/設定）→ 3タブ（**ホーム / 戦術 / 記録**）。設定はホーム右上の歯車へ。課題はホームと戦術詳細に溶かす。

## やらないこと（競合リサーチより）

映像/骨格解析、フォーム添削、相手スカウティングの作り込み、用具DB網羅、チーム映像管理。tt-tactics は「配球ログ×分岐×勝率×AI言語化」に集中する。

## 実装状況

- v1.1: ホーム画面（今日の一手＝決定的インサイト、今週の数字、AI 診断カード）、3タブ化、設定は歯車へ。`domain/insights.ts`（決定的インサイト）＋ `harness/insightAi.ts`（AI 診断）。
- 次段: 記録タブに練習ログ＋試合結果を統合、可視化（練習ヒートマップ・勝率トレンド）、試合結果の崩れ方1行・3択、ツリーの台上アニメ再生。
