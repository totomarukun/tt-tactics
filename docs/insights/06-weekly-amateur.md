# 06. 週1・時間が限られる中級プレーヤーが伸びる練習設計インサイト

対象ペルソナ（P1）: 市区〜都道府県大会に出る中級。シェーク両ハンドドライブ型。練習は週1回前後（クラブ／体育館）、試合は月1程度。最大の悩みは「何を練習すべきか分からない」。

一次情報・コーチ・研究・実プレーヤーの声を横断し、「発見 → 根拠（出典） → tt-tactics への具体設計（P1が使う場面つき）」でまとめる。汎用論は削り、「週1・時間が限られる中級」に固有の判断だけを残した。

---

## 発見1. 週1は「練習量で負ける」前提を受け入れ、時間配分を試合寄りに振り切る

**根拠。** 卓球村は身も蓋もない数字を出す。月1プレーヤーが月5時間なのに対し、弱小中学でも日1時間×週3で月20時間。この差は詰められない。つまり週1が量で並ぼうとするのは筋が悪い。卓トレ／タクティブが示す標準構成は「基本30分・応用40分」で、応用（実戦寄り）に最も時間を割き「ここで差がつく」と明言する。ラリーズも優先順位を「試合練習 ＞ 課題練習 ＞ 基本練習」の順とし、1時間なら基本15分・残り45分を課題と試合に回すと具体化している。中級以上ほど「好きなメニューに偏る」——これが伸び止まりの典型だとも指摘する。

**tt-tactics への設計。** 「今日の一手」カードに**時間配分プリセット**を持たせる。週1向けの既定比率を `基本:課題:試合 = 15:45:40（分）` としてホームに提示し、P1はそれを見て練習を始める。基本練習の枠は「短くていい」と明示し、罪悪感なく削れるようにする。
**P1が使う場面:** 体育館に着いてアプリを開くと、今日やる3ブロックが時間つきで並んでいる。何をやるか考える前に、卓球台の前で配分だけ確認して打ち始められる。

## 発見2. 「何を練習すべきか分からない」は、失点パターンから逆算すると解ける

**根拠。** tabletenniscoach.me.uk の弱点改善プロセスは第一歩を「直近の試合を分析的に振り返れ。どう失点したか。パターンは見えるか」と置く。butterfly／tabletenniscoaching.com も「弱点をピンポイントで特定し、その弱点をピンポイントで潰すドリルを組め」と説く。八戸卓球アカデミーやちょれ卓の卓球ノート術も共通して「得点／失点の流れ、サーブ・レシーブのパターンを追え」と書く。順序が肝心で、**練習メニューを探す前に「どこで負けたか」を1つ決める**。これが「何を練習すべきか分からない」の実体的な答えになる。

**tt-tactics への設計。** 既存の「試合結果に崩れ方1行＋敗因タグ」（04で設計済み）を、練習タブの入口に直結させる。敗因タグを確定した瞬間に「→この崩れ方に効く練習」を1件サジェストする流れは既に閉ループの核。ここに**「今週はこの1個だけ」フォーカス指定**を足す。頻出敗因ランキング上位1件を「今週の焦点」としてホーム最上部に固定表示する。
**P1が使う場面:** 月1の試合で「3球目を読まれて負けた」とタグした。次に体育館へ行くと、アプリのトップに「今週の焦点: 3球目の甘さ」と出ていて、迷わずその課題練習を選べる。

## 発見3. 技術の詰め込みより「試合で使うパターンを絞って反復」が週1では効く

**根拠。** ラリーズの「シンプルで効果の大きいシステム練習」は、ミドル攻めに絞る理由を明快に述べる。曰く核は「ミドル攻めを無意識にできるようにする」こと。「練習でしていないことが試合で突然できるわけがない」から、身体の使い方を染み込ませる。中級でミドルが有効なのは①コントロールミスのリスクが低い②相手が慣れていない、の2点。establetennis は構造化ドリルを踏む選手は自由打ち中心の選手より「習得が35〜50%速い」とする。週1でメニューを毎回変えて手を広げると、どれも試合で出せる水準（=無意識化）に届かない。狭く、深く、反復する。

**tt-tactics への設計。** 戦術ツリー（分岐図）と課題を紐づける既存構造を活かし、**「1本の勝ちパターンを反復対象に指定」**できるようにする。ツリーの根→決め球までの1経路を「今週の反復パターン」に登録すると、練習タブにそのパターンの多球／システム練習が並ぶ。反復回数を練習ログに積み、「このパターンを試合で使えた／使えなかった」を試合結果と接続する。
**P1が使う場面:** 「バックにサーブ→ツッツキ→ミドルへ3球目フォア」を今週の反復パターンに指定。練習では球出しでこの1本だけを繰り返し、次の試合でこのパターンが出せたかを1タップで振り返る。

## 発見4. 試合の悔しさは、24時間以内に「次の1回の焦点1〜2個」へ落とす

**根拠。** tabletenniscoach.me.uk の5ステップは「①弱点を認める（試合を分析）②なりたいプレーを決める③上級者/コーチに直し方を聞く④規則練習→不規則練習と段階を上げる⑤試合で無理にでも使う」。IMG Academy や After-Action Review 実務は「課題完了直後、記憶が新鮮なうちに」と揃って言う。tabletennisdailyacademy は映像レビューでも「一度に1つに絞れ。自分を責めすぎるな」と釘を刺す。焦点は多くて2個。1回の練習で扱えるのはそれが限界で、増やすほど無意識化に届かない。プロの振り返り→練習設計も同じ骨格で、「負けの分析 → 直したい1点 → それを潰す規則ドリル → 不規則化 → 実戦投入」を回す。

**tt-tactics への設計。** 試合を「lose」保存 → 崩れ方1行＋タグ（04）→ **「次の練習の焦点」を最大2個まで**選ぶステップを追加。3個目を選ぼうとするとソフトに止め、「絞るほど効く」を1行で添える。選んだ焦点はそのまま次回ホームの「今日の一手」に反映され、規則ドリル→不規則ドリルの2段階メニューに展開する。
**P1が使う場面:** 試合直後、悔しさが濃いうちにスマホで「決め急ぎ」「ミドルの甘さ」の2個だけ選ぶ。翌週の練習トップにその2個が焦点として出て、規則→ランダムの順でメニューが組まれている。

## 発見5. 練習動画は「撮る・見返す・紐づける」の軽量運用に絞る。高度解析はやらない

**根拠。** working カットマン氏やナニワ卓球道は、スマホ＋安い三脚で十分、カメラはフェンス高さ以上・コート後方に置くと全体（動き・戦術・配球）が見えると具体的に書く。tabletennisdailyacademy は「小さな点を時間をかけて追え」「一度に1つ」。ちょれ卓は撮って終わりにせず「毎回の練習とリンクさせてPDCAを回す」ことが変化の条件だと言う。プレーヤーの実感として重いのは「自分で仕掛けた得点は一部で、大半は相手のミス」——つまり動画を見ると"どのミスを相手にさせたか"が分かる。ここで大事な線引き: 骨格解析やAIフォーム添削は週1中級のリターンに合わない（00-synthesis の「やらないこと」とも一致）。撮影→30秒見返し→タグ紐づけ、までで止める。

**tt-tactics への設計。** 動画は**端末ローカルのクリップを1本、既存の試合結果 or 戦術ツリーに添付する**だけ。アプリ内編集や解析はしない。試合結果カードに「動画1本添付」フィールド、戦術ツリーの経路に「参考クリップ」リンクを持たせる。見返しは「この崩れ方タグの動画だけ集める」フィルタで、後から同じ失点パターンの映像を並べて見られる。撮影の推奨（後方・高め・1試合まるごと）はヘルプに1画面だけ。
**P1が使う場面:** 試合を1本スマホで撮り、負けた試合の結果カードに添付。家で30秒だけ見て「ミドルで崩された場面」を確認し、その試合の敗因タグに紐づける。次に同じタグの動画を並べると、繰り返す崩れ方が目で分かる。

## ★ 週1中級が伸びるための原則 Top5

1. **量で勝とうとしない。配分を試合寄りに振る。** 基本練習は短くていい。応用・試合形式に時間を集める（ラリーズ／卓トレ）。
2. **練習を探す前に「どこで負けたか」を1つ決める。** 失点パターンからの逆算が「何を練習すべきか」の答え（tabletenniscoach.me.uk／butterfly）。
3. **手を広げず、勝ちパターンを1本、無意識化するまで反復。** 「練習でしていないことは試合で出ない」（ラリーズ）。
4. **焦点は1回1〜2個まで。** 増やすほど届かない。悔しさが濃い24時間以内に決める（AAR／tabletennisdailyacademy）。
5. **動画は撮る・見返す・紐づけるだけ。** 解析はしない。PDCAに載せて初めて意味が出る（ちょれ卓／ナニワ卓球道）。

## ★ 試合の敗因 → 次の練習の焦点（1〜2個）に落とす推奨ワークフロー

1. **試合直後（会場で）**: 勝敗を保存 → 崩れ方を1行 → 敗因タグを最大3個（主因に星）。※04の低摩擦記録を利用。
2. **その場で焦点化**: タグから「次の練習の焦点」を**1〜2個**だけ選ぶ。3個目はアプリが止める。
3. **翌週ホーム**: 焦点が「今日の一手」に自動反映。規則ドリル → 不規則ドリルの2段階で展開。
4. **練習中**: 焦点に対応した多球／システム練習を反復。回数を練習ログに積む。
5. **次の試合**: 「その焦点は試合で出せたか」を1タップ評価。出せた→パターンを固定、出せない→もう1週継続。
6. **蓄積**: 頻出敗因ランキングでタグ出現率の低下を折れ線で確認（努力と結果の接続）。

## ★ 1回の練習の推奨テンプレ（週1・90分想定）

| ブロック | 時間 | 種別 | 中身 |
|---|---|---|---|
| ウォームアップ | 10分 | 基本 | フォア/バック対打、フットワークで身体を起こす |
| 基本（最小限） | 15分 | 基本 | 両ハンドの切り替え・ブロックの土台確認。長くしない |
| **課題（今週の焦点）** | **35分** | **多球/システム** | 焦点1〜2個に対応。規則ドリル→慣れたら不規則（ランダム70%返球が合格ライン） |
| **試合形式** | **25分** | **ゲーム練習** | 「今週の反復パターンを試合で出す」を目標に。得点/失点意識を持つ |
| クールダウン＋記録 | 5分 | 記録 | 練習ログに反復回数、気づきを1行。次回の焦点を仮置き |

要点: 基本を短くし、課題（多球/システム）と試合形式で6割超を使う。時間が45分しか取れない日は「課題25分＋試合形式15分」に圧縮し、基本は削る。

## ★ 軽量な練習動画活用の現実解と、やり過ぎない線引き

**撮り方（1画面のヘルプで足りる）**
- スマホ＋安い三脚。コート後方、フェンス高さ以上に置くと配球・動き・戦術が見える。
- 月1の試合は「1試合まるごと」を1本。練習は課題ブロックだけ短く撮る。

**見返し方**
- 見るのは30秒〜数分。「一度に1つ、小さな点」だけ。自分を責めすぎない。
- 見る観点は「どの失点パターンが繰り返すか」「どのミスを相手にさせられたか」。フォームの細部より配球と選択。

**アプリでの紐づけ案**
- 試合結果カードに「動画1本添付」。戦術ツリーの経路に「参考クリップ」。
- 敗因タグでフィルタし、同じ崩れ方の映像だけ並べて見られるようにする。

**やり過ぎない線引き（重要）**
- 骨格解析・AIフォーム添削・自動ハイライトは**作らない**（00-synthesis「やらないこと」と一致）。週1中級のリターンに見合わない。
- 動画編集機能を持たない。端末ローカルの1本を添付・参照するだけ。解析はP1の目に任せ、アプリは「撮ったものを失点タグに結びつける」役に徹する。
