# ペルソナと利用シナリオ（土台）

これまで機能はトピック単位のリサーチで積み上げたが、「誰が・いつ・どう使うか」の人物像が曖昧だった。ここを本人ヒアリング（2026-09-14）で確定し、全設計の土台にする。想像で埋めない。

## コアの一文

**「週1しか打てない中級プレーヤーが、その貴重な1回の練習で"何をやるか"を、試合の悔しさから迷わず決められる」**

すべての機能はこの一文に奉仕する。奉仕しないものは削るか後回し。

## 主ペルソナ P1: 週1・中級・大会に出る

- レベル: 市区〜都道府県の大会に出る中級。シェーク両ハンドドライブ型。
- 環境: **週1回前後**、クラブや体育館。まとまった練習時間は貴重で、次はいつ打てるか読みにくい。
- 目標: 大会で勝ちたい。負けた試合を悔しいと思う。
- **最大の痛み: 何を練習すべきか分からない。** 週1なので、その1回を無駄にしたくない。
- 情報行動（本人回答）:
  - 練習前に「今日やること」を確認したい。
  - 試合直後に結果を記録したい（悔しさが新しいうちに）。
  - 家でじっくり戦術を組みたい。
  - 練習中にも確認・記録したい。**「練習の質が上がる」仕掛け（例: 練習動画を撮って分析）に価値を感じる。**
- JTBD:
  1. 次の練習で何をやれば試合で勝てるか、迷わず決めたい。
  2. 本番で崩れる原因を減らしたい。
  3. 貴重な1回の練習の質を上げたい。

### P1 の1週間（ナラティブ）

平日の夜、家で前回の試合を思い返し、崩れた原因を眺めながら「次はこれをやろう」と考える余地がある。週末にクラブで1回だけ練習。月1くらいで大会。試合の直後、悔しさが残るうちにスマホで結果を残す。→ **気づきの全ては「次の1回の練習」に集約されるべき。** 週の歯車が遅いぶん、1回の焦点が全て。

## 利用シナリオ（タッチポイント）

1. **家・平日夜**: 前回の試合の崩れ方を見て、次の練習の焦点を決める／戦術を組む／AIに相談。→ アウトプットは「次の練習でやる1〜2個」。
2. **練習直前・移動中**: 「今日やること」を1画面で確認。迷いをゼロに。
3. **練習中・卓球台の横（片手）**: 今日の課題を確認、できた/まだを1タップ。ここに"質を上げる"価値（例: 動画クリップをその場で撮り戦術/課題にタグ付け、あとで見返す）があると強い。
4. **試合直後**: 勝敗＋崩れ方を数タップ。悔しさが動機になる唯一の窓。→ 崩れ方が次の練習の焦点になる。

## 機能の棚卸し（率直に。◎核 ○有効 △過剰/弱い ✕前提ミス）

| 機能 | P1 は使うか | 判定 | 対応 |
|---|---|---|---|
| ホーム「今日の一手」 | 練習前・家で見る核 | ◎ だが汎用的 | **「今週の焦点＝次の練習で何をやるか」を最上位に再フォーカス** |
| 戦術ツリー／台の図 | 家でじっくりの中心 | ◎ | 維持 |
| AI提案／Web調査／診断 | 家で「何をやるべきか」を埋める | ○ | **"今週の1回の焦点"へ落とす導線を強化** |
| 試合結果＋崩れ方 | 悩み(何を練習)の入力源 | ◎ | **崩れ方→次の練習の焦点に直結** |
| 練習ログ（日別カレンダー） | 週1だと日別は過剰 | △ | **「今日のセッションの焦点＋結果」に簡素化**、日別は副次 |
| 週目標（既定2回） | 週1なので前提ミス | ✕ | **既定1に修正。主指標は"回数"より"焦点を決めて練習したか"** |
| 練習ヒートマップ | 週1だと濃淡が薄く動機になりにくい | △ | 縮小・後回し。勝率/崩れ方の可視化を優先 |
| 台上アニメ再生 | 家での理解体験 | ○ | 維持 |

## 前提の修正（このヒアリングで判明した"甘さ"の是正）

1. **頻度の前提が違った**（週2-3想定→実際は週1）。週目標の既定を1に。継続の主指標を回数から「その1回が焦点通りだったか」に寄せる。
2. **ホームの主役を"今週の焦点"に**。試合の崩れ方→次の練習の焦点を自動で繋ぐカードを最上位に。
3. **練習ログを簡素化**。週1に日別カレンダーは重い。「今日の焦点＋できた/まだ」を主に。
4. **練習中の"質を上げる"価値を正式検討**。本人が明確に価値を感じる領域（動画クリップの撮影＋戦術/課題タグ付け＋見返し）。競合リサーチは「映像AIの作り込みは避ける」だが、"軽い動画クリップ"は週1中級にこそ効く可能性。骨格/AI解析でなく「撮る・紐づける・見返す」に限定して要検証。

## 非ターゲット（今は作らない）

- 毎日打つ本格層（別の設計思想が要る）。
- 映像の高度AI解析（14台カメラ/骨格推定/自動採点＝コスト過大、P1 に不要）。ただし軽量クリップは別枠で検討。
