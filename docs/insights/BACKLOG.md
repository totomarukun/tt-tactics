## 運用（リサーチ駆動ハーネス）

1. 改善・新規のたびに、対象領域の深いリサーチ（複数ソース・一次情報優先）を回し、`docs/insights/` に保存する。
2. 得た示唆を本バックログに芽として登録（根拠つき）。
3. 価値×工数で優先度を付け、上位から実装。実装は既存の設計原則（`00-synthesis.md`）に従う。
4. 実データ・利用から得た新発見も芽として追記し、退行はテスト（eval）で守る。
